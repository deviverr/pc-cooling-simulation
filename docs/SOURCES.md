# References and data provenance

Named power values are reference specifications. Geometry, fan curves, power budgets, and chassis limits are generic or editable assumptions; they are not exact vendor reproductions. Reference data checked October 2026; users should verify the exact product manual.

- [AMD Ryzen 7 9700X](https://www.amd.com/en/products/processors/desktops/ryzen/9000-series/amd-ryzen-7-9700x.html): 65 W default TDP.
- [AMD Ryzen 9000 series](https://www.amd.com/en/partner/articles/ryzen-9000-series-processors.html): 9900X 120 W and 9950X 170 W TDP.
- [Intel processor power reference](https://www.intel.co.uk/content/www/uk/en/gaming/overclocking-intel-processors.html): Core Ultra 7 265K 125 W base / 250 W maximum turbo power.
- [NVIDIA RTX 5070 family](https://www.nvidia.com/en-us/geforce/graphics-cards/50-series/rtx-5070-family/): reference total graphics power, 250 W / 300 W.
- [NVIDIA RTX 5080](https://www.nvidia.com/en-us/geforce/graphics-cards/50-series/rtx-5080/): 360 W reference graphics power.
- [AMD Radeon RX 9070 XT](https://www.amd.com/en/products/graphics/desktops/radeon/9000-series/amd-radeon-rx-9070xt.html): 304 W typical board power.
- [Noctua airflow setup guide](https://www.noctua.at/en/support/faqs/airflow-guide-setup-ideas): case intake/exhaust layout context.
- [GPU Gems, fast fluid dynamics](https://developer.nvidia.com/gpugems/gpugems/part-vi-beyond-triangles/chapter-38-fast-fluid-dynamics-simulation-gpu): projection-method background; not a claim of solver validation.
- [Corsair PSU cable compatibility](https://help.corsair.com/hc/en-us/articles/360025611351-PSU-Cable-Compatibility): exact modular cable compatibility matters.
- [Corsair CX-M manual](https://assets.corsair.com/image/upload/corsairmedia/sys_master/productcontent/WW_CXM_Series_2021_QSG_AA.pdf): CPU EPS and GPU PCIe connections are distinct.
- [Three.js](https://threejs.org/): rendering, orbit controls, and transform controls. MIT license in `web/vendor/THREE-LICENSE.txt`.
